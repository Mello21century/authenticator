Self-hosting guide

Quiet by design

A search box and your codes. Click a code to copy it; the ring shows how long it has left.

What happens to your secrets

The setup key behind each code is the thing worth stealing, so it never leaves the server.

Encrypted at rest

Each setup key is sealed with AES-256-GCM before it reaches the database, using a key that lives only in the server's settings.

Codes are made on the server

Your devices receive the six digits and nothing else. A lost laptop or phone holds no setup keys.

Locked until you prove it's you

The apps lock every time they start and again after an hour, or sooner if you choose. Codes stay hidden until you unlock.

Your own account has 2FA too

Protect your sign-in with a code from any authenticator, with ten one-time recovery codes as a backup.

The trade-off: because codes are made on the server, you need a connection to see them. If you need codes on a plane with no Wi-Fi, keep a second authenticator for your most important accounts.

Share with family or your team

Invite people to your account and pick which codes each person can see. Shared codes are read-only, and everyone keeps their own private codes alongside.

Run your own server

The server is one Docker Compose file: the API, the web app and MongoDB.

  1. Get the code

    git clone https://github.com/Mello21century/authenticator.git
cd authenticator

  2. Create two secrets

    cp .env.example .env
openssl rand -base64 48   # JWT_SECRET
openssl rand -base64 32   # VAULT_MASTER_KEY, back this one up

  3. Start it

    docker network create dokploy-network
docker compose -f docker-compose.yml -f docker-compose.local.yml up -d --build

    Open http://localhost:8080 and create your account. The self-hosting guide covers domains, email and backups.
