User guide

Everything you can do in Space Authenticator, on every device.

Create your account

Open authenticator.sz4h.com or any of the apps and choose Create account. Use a password of at least 10 characters. The same email and password sign you in everywhere.

Add an account

When a website shows you a QR code to set up two-factor authentication, choose + in Space Authenticator and pick one of these:

  • Scan with your phone: the mobile app opens the camera and reads the QR code.
  • QR image: on the web and desktop, upload a screenshot of the QR code or paste it from the clipboard.
  • Link: paste an otpauth:// link if the website offers one.
  • Type it in: enter the setup key the website shows under "can't scan the code?".

Type the six-digit code back into the website to finish. The account appears on all your devices right away.

Copy a code

Click or tap a code to copy it. The ring next to each code shows how long it has left; it turns amber in the last five seconds, so wait for the next code if you're a slow typist. Start typing to search: the search box is focused whenever you open the app.

Lock and unlock

The Mac, Windows, mobile and Chrome apps hide your codes until you unlock them. They always lock when they start, and lock again after the time you choose in Settings → App lock: 1 minute, 15 minutes, 1 hour (the default), or only when the app restarts.

The web app in a browser tab doesn't lock; sign out when you leave a shared computer.

Chrome side panel

The extension opens your codes in Chrome's side panel next to the page you're signing in to.

  1. Download the extension zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Choose Load unpacked and select the unzipped folder.
  4. Pin Space Authenticator from the puzzle-piece menu.

Open it with the toolbar icon or ⌘⇧2 (Ctrl⇧2 on Windows). If you have an account for the site in the current tab, the search is already filled in, so the right code is the only one showing. You can change the shortcut at chrome://extensions/shortcuts.

The first time you unlock, Chrome asks to create a passkey for the lock. It stays on your device and is only used to unlock the panel.

Install the apps

Mac

Download the Apple silicon or Intel version (Apple menu → About This Mac tells you which), open it and drag the app to Applications.

If macOS says the app "can't be checked for malicious software", open System Settings → Privacy & Security and choose Open Anyway. This goes away once releases are notarized by Apple.

Windows

Run the installer. If Windows shows "Windows protected your PC", choose More info → Run anyway. The app keeps running in the system tray when you close its window; right-click the tray icon to lock or quit.

As a web app

In Chrome or Edge, open the web app and choose the install icon at the right of the address bar. It gets its own window and icon without downloading anything.

Import from another app

Go to Settings → Import, then choose a file or paste text. Accounts you already have are skipped.

AegisExport as a plain (unencrypted) JSON file
2FASExport a backup without a password

Anything elseA list of otpauth:// links, one per line
Unencrypted exports contain your setup keys. Delete the file once the import is done.

Export a backup

Settings → Export downloads every account you own as otpauth:// links in a JSON file, which you can import here again or into most other authenticators. You'll confirm your password first (and a code, if you've turned on two-factor sign-in). Codes shared with you by someone else are not included. Store the file somewhere encrypted.

Family and team members

The account owner can invite people in Settings → Members. Each person gets an email to set their password. Then, from the ⋯ menu on any account, choose Share and tick who should see it.

  • Members see shared codes but can't see the setup key, edit or delete them.
  • Members can add their own private accounts, which the owner can't see.
  • Removing a member deletes their access and their account.

Protect your own sign-in

Turn on two-factor sign-in in Settings → Two-factor login: scan the QR code with a different authenticator (not this one), enter a code and your password, and save the ten recovery codes somewhere safe. Each recovery code works once if you lose that authenticator.

Forgot your password

Choose Forgot password? on the sign-in screen. The email link works for 30 minutes and only once. Resetting your password signs you out on every device.

Use a different server

The desktop, mobile and Chrome apps connect to authenticator.sz4h.com. If you run your own server, open Server on the sign-in screen and enter its address, ending in /api.
